# mom-photography

Photography portfolio with an admin area for uploading, arranging and publishing photos.

TanStack Start + shadcn/Tailwind v4, deployed to Vercel.

## Local setup

1. `pnpm install`
2. `pnpm dev` — the app runs on http://localhost:3000

## Deploy

Vercel builds the app with Nitro, which picks the Vercel preset on its own. Import the GitHub repository in Vercel; every push to `main` deploys to production and every PR gets a preview.
